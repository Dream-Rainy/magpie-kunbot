# 模型测试与请求诊断

状态：用户明确要求增加测试功能，作为既有管理页的增量实施。

在配置页增加“模型测试”入口，打开同插件的额外界面。先保存配置，再选择已登录账号与已暴露模型；默认生成所选协议的最小 JSON 请求，允许编辑。支持只预览及主动发送测试，展示每个实际尝试的地址、方法、脱敏请求头、真实请求体、状态码、耗时、响应与异常。提供取消、重新载入、复制诊断；不自动发送模型请求。

采用 Magpie 的 page.service：后端仅监听 127.0.0.1，Web 经 magpie.service 代理；静态管理页的沙盒权限保持原状。服务从宿主传入的 directory/plugin-auth.json 读取当前应用账号，筛选 kunbot，仅返回账号标识与名称。发送前重新读取，不保留退出账号的 Key。Key 只在后端使用，不放入页面、Options 或诊断。

测试重用 modelTable 与 forwardRequest，包括模型后缀、账号地址覆盖、真实模型 ID 和同协议主备；增加仅诊断时开启的追踪和预览选项，不影响正常请求。预览也走相同的候选构造，实际发送才执行 fetch。诊断按模型 SDK 默认 Chat、Messages 或 Responses；图片用 images/generations，语音合成用 audio/speech。当前面板以 JSON 为输入，文件上传与真实 Magpie 网关协议转换不在本次范围。

服务校验回环 Host 与页面来源；API 要求随机会话令牌，HTML 不开放 CORS，令牌只保存在本次页面内存。只接受已配置模型与预设操作路径；不接受任意 URL、Key 或账号文件路径。请求体最多 64 KiB，响应最多读取 64 KiB，二进制和图片 base64 用摘要表示；记录对凭据字段、当前 Key 和错误中的 Key 脱敏。测试具有超时、取消及并发限制；结果不落盘。

测试界面是插件直接请求上游的诊断工具，能定位端点、协议、请求体、账号和主备问题；不声称覆盖 Magpie 对 agent 请求的全部转换。明确提示发送测试可能计费，只有点击发送才调用模型。已有配置页、登录与模型列表继续可用；服务端口冲突不阻断供应商加载。

验证覆盖：预览不发模型请求、请求体与实际一致、主备失败详情与真实 ID、Chat/Messages/Responses/Images、账号隔离与退出、Key 脱敏、超时取消、响应上限、服务访问校验；用本地模拟上游完成原生 v0.1.4267 浏览器测试，不使用真实 Key 或付费模型。

## 0.3.1：桌面端返回修复

用户反馈测试页返回时 wails.localhost 拒绝连接。原返回依赖 history.back，会跨回 Wails 虚拟资源主机；Windows 的外部沙盒框架请求可能不被虚拟资源处理器接管。

修复不依赖历史记录或直接重写 Wails URL。在本地服务提供 `/config/index.html` 及现有配置页资源，返回按钮明确替换为同一服务下的配置地址；打开测试也替换当前历史项。服务版配置页用最小 postMessage 桥接复用 Magpie 父窗口的 hello、options.get/set 和主题事件，按官方协议仅接受父窗口回信；不向 Wails 请求脚本或样式，不改动配置与凭据的存储入口。服务根地址从配置页自身的父路径解析，兼容桌面直连和 Web 服务代理。

验证包括：在 http://wails.localhost 父窗口中首次加载配置后阻断其全部资源请求，仍可测试→返回→读取/保存配置→再次测试；完整原生 Web 服务代理流程继续通过。Linux 容器内的 Windows 来源模拟不等同于实际 Windows WebView2 验证。
